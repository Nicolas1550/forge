**Modificaciones para FORGE V2.3:** se eliminó el suelo original de exhibición, se separó el gabinete estático del vidrio y se agruparon mallas candidatas para GPU, RAM, AIO y ventiladores mediante FORGE 3D STUDIO V2; se mantuvieron sus coordenadas compartidas y se reempaquetó la geometría para uso web. Se creó un sistema interactivo de desmontaje, zoom, montaje visual y cámara en Three.js. El modelo original se conserva en el archivo suministrado por el usuario.

Los archivos de terceros incorporados están en `public/models/forge/modular/`. Sus nombres internos, marcas comerciales y geometrías **no certifican** que las piezas 3D representen exactamente un producto que figura en el catálogo. Las mallas de AIO y ventiladores requieren validación visual de detalle.

En la página se conserva un enlace visible al autor y a la licencia. El crédito debe mantenerse al publicar o distribuir una versión derivada.
